# Conquer Carniato

Estúdio que desenvolve e opera o **Carniato**, um servidor privado de Conquer Online (versão 6609).

## O que a gente faz

- Servidor de jogo em C# (Dream.Kernel/Dream.Game/Dream.Ai)
- Portal web (ASP.NET Core + React) pra conta, ranking e loja
- Launcher e overlay nativo do cliente
- Cliente experimental e servidor nativo em desenvolvimento
- Conteúdo, wiki e material de divulgação

## Repositórios

Todos os repositórios são privados; acesso é liberado por projeto conforme a necessidade de cada colaborador.

| Repositório | O que é |
|---|---|
| `conquer-workspace` | Workspace do operador — organiza e clona todos os projetos |
| `conquer-server` | Servidor C#, módulos, Lua, migrations |
| `conquer-portal` | Portal ASP.NET Core + React |
| `conquer-launcher` | Launcher e DLL de overlay nativa |
| `conquer-client` | Cliente de jogo experimental |
| `conquer-server-native` | Servidor nativo experimental |
| `conquer-content` | Wiki, marketing, assets editoriais |

Se você é colaborador, comece clonando o `conquer-workspace` — o README dele tem o passo a passo pra clonar o resto.
